DipTrace — заполнение пропусков позиционных обозначений

Автономный HTML-инструмент для файлов .dchxml (экспорт схемы DipTrace). Работает локально, без отправки проекта на сервер.

Перетащите сюда файл .dchxml

или выберите его на компьютере

Настройки

Выберите группы для устранения пропусков. Номера уплотняются в порядке возрастания: например, C1,C2,C4,C7 → C1,C2,C3,C4. У многосекционных компонентов обозначение остаётся общим.

По умолчанию исключены NetPort. Выбор других групп доступен вручную. Поля библиотеки компонентов не затрагиваются.

Важные ограничения

Меняются только значения тегов <RefDes> внутри <Schematic><Components>. XML не сериализуется заново: остальное содержимое исходного файла, порядок элементов, форматирование и идентификаторы сохраняются побайтно (за исключением изменённых обозначений). Проверяются уникальность после перенумерации и корректность XML. Перед использованием в рабочем проекте сохраните исходник и проверьте файл в DipTrace, особенно если имеются внешние ссылки на прежние RefDes или синхронизация с PCB.
