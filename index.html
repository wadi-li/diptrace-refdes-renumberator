DipTrace — заполнение пропусков позиционных обозначений

Автономный HTML-инструмент для файлов .dchxml (экспорт схемы DipTrace). Работает локально, без отправки проекта на сервер.

Настройки

Выберите группы для устранения пропусков. Номера уплотняются в порядке возрастания: например, C1,C2,C4,C7 → C1,C2,C3,C4. У многосекционных компонентов обозначение остаётся общим.

В скобках: уникальных обозначений / размещений (секций). По умолчанию исключены NetPort. Поля библиотеки компонентов не затрагиваются.

Важные ограничения

Меняются значения тегов <RefDes> внутри <Schematic><Components> и, если включено, отмеченные упоминания в <TextLine> схемы: текстовые надписи, поля основной надписи и ячейки таблиц. Упоминание распознаётся как отдельное слово: C11=12n, C5-C8, R16, R17. Фрагменты вида NE8FAH-C5 или R1.5 помечаются как сомнительные и по умолчанию не заменяются. Значения, имена и дополнительные поля компонентов не изменяются.

XML не сериализуется заново: остальное содержимое файла, порядок элементов, форматирование и идентификаторы сохраняются побайтно. Проверяются корректность XML, число секций и уникальность обозначений. Перед использованием в рабочем проекте сохраните исходник и проверьте файл в DipTrace, особенно при синхронизации с PCB.
